# Fact Sheet v1 — 수학 연산 검증용 기준표

작성 2026-08-18. 등록된 지표 8종의 대상·차원·시간범위·사실값을 원천에서 직접
계산해 정리했다. 목적: 수학 연산 성능 검증 질의문의 생성과 채점. 모든 수치는
결정론적으로 재현된다(질의 윈도우 또는 `run.py --route c4`).

## 0. 질의 작성 규칙

- **지표는 등록 별칭으로**: 매출/순매출 · 영업이익 · 보험 손해율/손해율 ·
  재고/재고 잔액 · 활성 고객 수 · 강수량/강수 · 불량률 · 검사수/검사 부품 수
- **시간 표현**: `N월`(기본 연도 2026) · `2015년 3월`(명시 연도는 같은 질문의
  연도 없는 월에 전파) · `W29`/`29주차`(ISO 주) · `U0300`(익명 구간). 비교는
  `X 대비 Y`.
- **scope**: 차원 값을 질문에 그대로 (예: "온라인", "가전", "L0-L3", "snow")
- **단위 환산**: 매출·영업이익의 `u` = 0.1억원 → 표시 시 ×0.1 "억" (3860u =
  386억). 손해율·불량률은 ratio(×100 = %).

## 3. 영업이익 (u, signed)

원장 전체: 6월 리테일 +100·기업 −20 (합 **80**) / 7월 리테일 +70·기업 −50
(합 **20**). Δ −60 (리테일 −30·기업 −30). 음수는 정상 정의역.

## 4. 손해율 (Σ분자/Σ분모)

원장: 6월 A 40/100·B 90/100 / 7월 A 72/120·B 60/80.

- 6월 = 130/200 = **0.65** · 7월 = 132/200 = **0.66**
- region별 7월: A = 0.60 · B = 0.75 / 6월: A = 0.40 · B = 0.90
- **함정 검증**: 7월 단순평균 (0.60+0.75)/2 = 0.675는 오답 — 시스템은 분모
  가중만 허용. 변화 분해·기여도 요청은 거부되어야 정답.

## 5. 재고 잔액 (월말 시점, 개)

6월말 서울 100·부산 80 (합 **180**) / 7월말 서울 120·부산 70 (합 **190**).
Δ +10 (서울 +20·부산 −10). 시간 축 합산(6+7월 합 370 등)은 무의미 — balance.

## 6. 활성 고객 수 (distinct, 명)

6월: c1·c2(서울)+c3(부산) = **3** (서울 2·부산 1) / 7월: c1·c2·c4(서울)+
c3·c5(부산) = **5** (서울 3·부산 2). Δ +2 — 전이: 진입 c4·c5, 이탈 0, 이동 0.
중복 행 존재(c1 6월 2행, c2 7월 2행) — distinct가 이를 흡수해야 정답.

## 10. 검증자가 알아야 할 계산 규칙

- 가법 합(매출·영업이익·강수량·검사수): 세그먼트 합 = 총계, Δ 분해 항등식
  Σ세그먼트Δ = 전체Δ (계약이 identity_recheck로 검사)
- 분모 가중(손해율·불량률): Σ분자/Σ분모. 세그먼트 비율의 평균·합은 오답
- 월말 시점(재고): 기간 합산 무의미, 세그먼트 합만 가법
- distinct(고객): 중복 행 흡수, 세그먼트 Δ는 set 전이(진입/이탈/이동)로만 설명
- pct_change = Δ/이전 ×100 (반올림 1자리)
- 버킷 소속 = floor(t/100)×100 · ISO 주 = 월요일 시작, 연-주 라벨
