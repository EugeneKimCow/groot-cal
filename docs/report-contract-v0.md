## 0. 역설계의 3대 발견

1. **어조 전환점 = 라벨 경계.** 5개 표본 전부에서 "어디서 빠졌나"(분해)는 100% 단정 어조이고,
   "왜 빠졌나"(원인)에서 헤지가 시작된다 — 이 전환점이 '데이터 확인'→'데이터 시사' 경계의
   지면상 위치와 정확히 일치한다. **계약은 라벨을 새 개념으로 도입하는 게 아니라, 인간이
   이미 서술어 선택으로 수행하는 등급 표시를 명시화하는 것이다.**
2. **숙련 표본에서 "때문이다/기인한다" 단정형은 0회다.** 인과는 세 형태로만 나타난다:
   (a) 산술로 닫힌 등호 서술, (b) 헤지 어미 하의 시사, (c) 부정·차단 수행문("~는 무리다").
   서사 린트는 발명이 아니라 숙련자 관행의 기계화다.
3. **제5의 문장 유형 T5(메타-인식론 문장)가 실존한다.** "확실한 것은 여기까지다",
   "잔차 귀속이지 확인이 아니다" — 인간 숙련자는 금지 규칙을 침묵으로 지키지 않고 **소리 내어
   지킨다.** 라벨 상한 선언이 독립 문장 유형으로 지면에 존재한다.

## 1. 공통 골격

```
S0. 헤더 메타        작성 주체·작성일·수신자·대상 기간·비교 기준 — 시점 정합의 앵커
S1. 헤드라인 판정    ①규모(Δ·%) → ②구조("몸통은 X") → ③성격(일시 vs 구조) → ④상쇄·안심 신호
S2. 정량 분해        "어디서" — 지배 축 먼저, 최소 분해 깊이까지만. 어조 100% 단정
─── 어조 전환점 (= 확인→시사 라벨 경계) ───
S3. 원인 대조        "왜" — 이벤트를 증거 강도 내림차순 배열, 성격 태그+정합 수치 병기
S4. 불확실성 블록    확인 상한 선언 → 양방향 단정의 대칭 기각 → 최대 허용 문장 → 필요 데이터
S5. [장르 스위치]    상쇄·긍정 요인 / 기각 대안(Q&A 장르) / 계획 대비(S&OP는 전체 기준축)
S6. 전방 참조        관전 포인트 — 각 시사·판단에 판별 시점+판별 데이터+재분류 규칙 부착
S7. 후속 행동        담당·기한·용도. S4의 미보유 데이터가 여기서 요청으로 변환
S8. [조건부] 푸터    수치 출처·비교 기저 선언 / 검산 부록(분석가 노트만)
```

모든 표본이 후속 행동으로 종결한다 — **이 장르의 보고서는 닫힌 결론이 아니라 다음 확인으로
여는 문서다.**

## 3. 렌더링 사전 — 라벨의 지면 표기법

**관료적 태그를 지면에 찍지 않는다.** 라벨은 종결어미·서술어 선택으로 구현한다. 작문(⑧)은
사전에서만 어미를 고르고, 린트(⑨)는 역방향 검사(어미→라벨 정합)를 한다.

| 라벨 | 허용 서술어 | 비고 |
|---|---|---|
| 데이터 확인 | ~이다/~였다/~를 차지한다, 명사형 ~임/~됨(사실 서술), "산술로 닫힘", 등호 서술("= A + B") | 볼드 허용 대상 |
| 데이터 시사 | ~로 보인다, ~와 정합한다, "~만으로 설명 **가능한** 크기다", 2단 헤지("~했을 가능성이 크고 ~일 수 있다") | **의무: 같은 문장 안에 정합 근거(기간 일치·세그먼트 일치·규모 커버 중 1+) 동반** |
| 컨설턴트 판단 | ~권합니다, ~검토/제안/토록 함, ~할 필요가 있다, 기각 판정("아님"/"설명력 약함") | 근거 수치 역참조 필수 |
| 참고치 | "(잠정 집계상)", 방향성만 수치 없이("소폭 회복된 수준") | **숫자를 지면에 올리지 않는 것 자체가 표기법** |

**보조 장치 3종**: ① 상한 선언문 관용구 — "확실한 것은 여기까지다: X" (애매함이 있는 보고서는
1개 의무화 후보), ② 구조에 의한 등급 분리 — 섹션 위치 자체가 라벨(확인은 S2에, 판단은
recommendations에만), ③ 말미 기저 선언 — comparison_basis의 인간 관행형.

**예약어 규칙**: 시사의 정본은 "보인다/정합/설명 가능" 계열. "~로 판단됨"은 시사
허용-비권장(deprecated), 능동형("판단함/권고함")은 판단 라벨 전용으로 예약 — '판단' 어간의
라벨 충돌 방지.

## 4. 인과 어법의 경계

**경계 규칙 한 문장**: 인과 문장의 라벨 상한 = f(이벤트 금액 특정 여부, 정합 증거 수) —
금액 특정 + 항등식 닫힘 → **확인급 등호 서술** 허용("호남 -5.0 = 폐점 -5.2 + 잔여점 +0.2";
인과 동사 없이 분해가 인과를 대신) / 정합 증거(기간·세그먼트·규모) ≥ 1 → **시사**, 단
배타성 표현("전부", "확인됐다") 금지 / 증거 없음 또는 잔차 논법 → **차단 또는 판단
라벨 + 근거 참조**. (legacy-notes "경로의 존재는 확인, 설명 언명은 시사 이상 불가"와 합치.)

차단 목록 (표본이 스스로 그은 경계):
- **인과어 + 확인 동사**: "경쟁사 행사 영향이 확인됐다" — 무조건 차단.
- **배타적 단일 원인**: "프로모션 종료가 전부" — E2 영향이 0이라는 별도 주장을 몰래 얹는 것.
- **잔차 귀속**: "남는 -3~-4억은 경쟁사 행사분" — 3개 표본이 삼중 차단. 예외: 후보 원인
  전원의 금액이 특정될 때만 잔차 논법 성립.
- **미특정 원인의 정량 분해 표** — 거짓 정밀도.
- **반사실 신수치**: "뷰티가 없었다면 -42.0억" — 항등식이어도 새 숫자를 낳고 서사를 과장.

경계 위의 문장 (교육용 대조): "~만으로 -24.0 전체를 설명할 수 **있는** 규모다"는 허용
(양상 조동사가 규모 정합성만 주장) — '있는'을 빼는 순간 차단 대상이 된다.

## 5. 문장 유형 5종과 장르별 예산

T1 사실 진술 / T2 산술 귀속 (T1과 어조 동일 — 출처로만 구분) / T3 해석·추정 (헤지 개시) /
T4 판단·권고 / **T5 메타-인식론** (상한 선언·승격 차단 — 이번 역설계의 최대 발견).

| 장르 | T1+T2 | T3 | T4 | T5 |
|---|---|---|---|---|
| 주간 브리핑 | ~33% | ~28% | ~28% | ~11% |
| CFO 메모 | ~40% | ~30% | ~25% | ~5% |
| 경영진 1p | ~35% | ~35% | ~30% | 0% — **숫자 은폐로 대체** |
| 분석가 노트 | ~65% | ~15% | ~10% | ~10% |
| S&OP 브리프 | ~45% | ~25% | ~30% | 미미 |

- **T4 예산은 독자의 결정 근접도에 비례**(내부 노트 10% → 경영진 30%) — audience 파라미터가
  T4 예산을 정한다.
- **T5의 구현 형태는 독자에 따라 문장 ↔ 편집으로 전환된다**: 분석가 노트는 차단을 문장으로
  쓰고, 경영진 1p는 같은 차단을 숫자 생략으로 수행한다(-9.2 갭 미인용 — "수치를 제시하면
  귀속하고 싶어진다").

## 6. 표 규약

1. **표는 미해결·판정 축에만** — 이미 닫힌 문제(폐점으로 설명된 권역별)는 산문 강등.
2. 표준 열: 세그먼트 | 전월 | 당월 | Δ | 전월비% [| 기여도%] [| 장르별 열]. 합계 행 볼드 +
   반드시 닫힘(Σ==전체).
3. 표 개수 상한: 경영진·S&OP 1개("한 표에서 판정이 한눈에"), CFO 0개(팩트 시트 중복 회피),
   주간 2개, 분석가 무제한 + 검산 부록.
4. **표는 스캔용, 본문은 판정용** — 판정에 쓰이는 수치는 본문 문장에 재소화.
5. 기여도% 인용 규율: 100% 분해의 다축 반복 인용 금지. 스토리 등뼈만 산문 인용.
6. 파생 수치 금지선: 팩트 밖 파생 열 금지, 반사실 합산 금지, 미특정 원인 곁의 잔차 수치 회피.

## 9. 불확실성과 기각의 규칙

**불확실성의 상품화** — 어떤 표본도 '모른다'로 끝내지 않는다. 분리 불가는 반드시 4요소로
가공된다: ① 확인 상한 선언 ② 불가 이유 특정("이 데이터가 없어서 이 구분이 안 된다") ③ 해소
경로(필요 데이터+시점+담당) ④ 판별 실험("행사가 주범이면 종료 후 회복, 기저효과면 지속" —
elaborate theories의 자연어형). 후속 행동 섹션은 사실상 ambiguity_block의 출력 큐다.

**기각의 규칙** — ① 기각 1건 = 판정 1어("아님") + 반증 수치 최소 1개(수치 없는 기각은 표본
전체 0건) ② 기각에도 등급("아님" vs "설명력 약함") ③ 기각하면서 교란을 자백("~도 폐점 효과와
겹칩니다" — 신뢰도를 오히려 높임) ④ 기각 대상은 독자가 물을 통념 가설이지 허수아비가 아님.

## 10. 린트 규칙 v0 (정규식 수준)

- R01 인과 단정 차단: `(때문이|기인하|의 결과다|이 원인이다)` AND 헤지 토큰 부재 → 차단.
  판단 라벨 문장은 경고 + 근거 참조 요구.
- R02 인과어+확인 동사 결합: `(영향|원인|효과|탓)…(확인|입증|규명)(됐|되었|됨)` → 무조건 차단.
- R03 배타적 단일 원인: `(전부|전적으로|만으로)…설명(한다|했다)` 에서 양상 조동사 부재 → 차단.
- R04 잔차 귀속: `(나머지|잔여|남는|잔차)…(전부|모두|전액)…(영향|귀속|때문)` → 차단.
  예외(구조 검사): 후보 원인 전원이 금액 특정 필드를 가질 때만.
- R05 반사실 신수치: `(없었다면|아니었다면)` 문장 내 새 합계 수치 → 차단. 반사실 절 자체는 경고.
- R06 수치 출처: 본문 수치 전수 추출 → Bundle 수치 + 등록 항등식 파생치 화이트리스트 대조,
  미등재 → 차단.
- R07 어미-라벨 정합(역방향): 확인 라벨에 시사 어미 → 경고(과소 라벨); 시사 라벨에 판단 어미
  → 경고(재지정).
- R08 시사 근거 동반: 시사 어미 문장에 근거 토큰(수치·기간·등록 이벤트명) 0개 → 경고.
- R09 기각 반증 수치: 기각 토큰 포함 불릿에 수치 0개 → 차단.
- R10 분리 불가의 해소 경로: "분리 불가/특정할 수 없" 존재 시 후속 데이터 요청 블록 부재 → 차단.
- R11 미래 단정: 미래 표현 + 단정 종결 AND 조건절 부재 → 경고("예상/전망" 어미 또는 조건절 요구).

## 11. v0.1 후보 (미해결)

1. 상승 보고서의 어법 — 표본이 전부 하락 시나리오. 상승 원인 단정은 관대해질 가능성(표본 필요).
2. T5 메타 문장을 에이전트가 쓸 때의 어색함 — 인간의 "확실한 것은 여기까지다"가 에이전트
   지면에서 자연스러운가.
3. 시각화 규약 — v0는 표만. 차트에서의 라벨 구현(확인 수치와 시사 수치의 시각 구분)은 감사
   지적대로 별도 작업.
4. R04 예외 조건·"유인 수치의 부재 선택"(숫자 은폐 전술)의 기계 검사 구현.
5. 실보고서 3~5건 확보 시 가상 표본과의 대조 개정.
