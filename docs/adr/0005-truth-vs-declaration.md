# ADR-0005: 참 규모와 신고치의 분리 — 선언은 오염이 기본값

- 상태: Accepted · 2026-08-11 · 커밋 efa9110 (Track 2a)

## 맥락

이벤트 레지스트리의 신고치("마케팅팀 집계 약 30억", "점포 단위 신고")는
현실에서 부정확하다. v0는 이 오염을 시나리오 작가가 손으로 심었고, 시뮬레이터
초판은 가법 이벤트의 실현치를 그대로 신고해 **신고-실현 괴리라는 시험 대상
자체를 설계에서 소거**하는 결함이 있었다 (적대 검증 CONFIRMED).

## 결정

시뮬레이터는 참 규모(truth.json)와 신고치(events.json)를 분리 생성하며,
신고는 오염이 기본값이다. 선언 정책:

| 정책 | 의미 | 오염 |
|---|---|---|
| exact | 명목 주입치 신고 (가법 이벤트) | 배분·클램프로 실현과 괴리 — 그 괴리가 시험 대상 |
| noisy1 / noisy3 | 실현치 ±1% / ±3% 신고 잡음 | 절단 정규(±2σ) — 고정 시드의 극단 draw가 벤치마크에 박제되는 것 방지 |
| ref_noisy | 규모 미특정 + 참조 스케일 ±15% | "팀 집계" 수준의 부정확성 |
| none | 무수치 (트래픽 데이터 미보유 등) | — |
| decoy | 등록만 있고 실제 효과 0 | 기각 시험용 |

선언 잡음의 rng는 이벤트 id로 고정해 시나리오 간 재현 가능. 가법 이벤트의
truth에는 명목(injected_u)과 실현(target_slice_delta_effect_u)을 병기한다.
dirty 시나리오의 truth에는 오염 전·후 총계를 모두 기록해(monthly_totals_u /
ledger_monthly_totals_u) 소비자의 오대조를 방지한다.

## 결과

- 신고 오차가 채점 가능한 1급 시험 대상이 됨: E4 명목 -5.5억 vs 실현 -5.2억
  → 선언오차 -0.3억이 채점표에 실측으로 등장.
- 이벤트 레지스트리의 '산술 대조 가능(규모 특정)' 등급이 신고 정확도와
  분리됨 — 특정된 신고도 틀릴 수 있고, 그 오차의 크기가 라벨 상한 논의의
  재료가 된다.
- lint 화이트리스트의 외부 신고치 등급 분리(방향성 검토에서 지적된
  '확인 세탁' 경로 차단)의 실험 기반.

## 재검토 조건

실데이터 온보딩 시 실제 신고 오차 분포를 관찰해 정책 파라미터(±3%, ±15%)를
현실화.
