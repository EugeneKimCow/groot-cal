# ADR-0003: 기권 채점은 계약 R04와 정합한다 — 전원 특정 시에만 잔차 논법

- 상태: Accepted · 2026-08-11 · 커밋 efa9110 (Track 2a)

## 맥락

score.py 초판은 중첩 이벤트 쌍에서 "무선언 ≤ 1이면 잔차 귀속 가능(전원-1 특정)"
으로 채점했다. 이는 계약과 정면 충돌한다 (적대 검증 CONFIRMED):
report-contract-v0 §4·R04는 "후보 원인 **전원**의 금액이 특정될 때만 잔차 논법
성립"으로 규정하고, exemplar 표본과 kernel의 overlap 플래그도 같은 차단을
수행한다 — 계약·표본·커널 3층이 차단하는 행위를 채점층만 허용으로 분류했다.

## 결정

1. 채점 정책을 계약에 정합화: **무선언 ≥ 1 → 기권**이 옳은 행동.
2. 다만 차단된 '전원-1' 잔차 귀속을 **시험 삼아 수행한 오차를 실측**해
   `separation_justified`(|오차| ≤ 15%·|공유 Δ|)로 병기한다 — 차단의 정당성을
   수사가 아니라 수치로 남기기 위함.
3. 계약이 허용하는 유일한 잔차 논법(전원 특정)을 실제로 시험하기 위해
   overlap_specified 시나리오를 추가한다 (양 이벤트 모두 선언 → 선언 대조 채점).
4. 판정에 쓰이는 값은 라운딩 전 값으로 비교한다 (banker's rounding이 임계
   비교를 뒤집은 사례 재발 방지). 선언 오차의 부호 규약은 **선언 − 참**
   (양수 = 과대 신고)으로 전 채점 항목 통일.

## 결과

- 첫 실측: '전원-1' 시험 오차가 케이스 따라 갈렸다 — fall E3+E5 분리 부당
  (오차가 공유 Δ 대비 큼), overlap_pinned E1+E2 분리 정당화 가능.
  **케이스가 갈린다는 사실 자체가 일률 차단(R04)의 근거다**: 사전에 어느
  쪽인지 알 수 없으므로.
- 무선언 쌍의 기권은 naive 배분 전략(반반/전부/참조 비례)의 최선 오차 실측으로
  정당화됨.
- 계약 개정(전원-1 예외 도입) 여부는 이 실측을 근거로 v0.2 미해결 항목에서
  판단한다 — 채점이 계약을 앞질러 완화하지 않는다.

## 재검토 조건

⑧작성층 루프 측정에서 LLM의 기권 행동을 같은 잣대로 채점할 때, 정책 채점
(결정론)과 서술 채점(작문)의 결과가 크게 어긋나면 임계(15%) 재조정.
