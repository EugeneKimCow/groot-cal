# ADR-0004: 통상 변동 대역은 검정이 아니라 설명 요구 트리거다

- 상태: Accepted · 2026-08-11 · 커밋 efa9110 (Track 2a)

## 맥락

δ_min(현행 2억)의 자의성을 보완할 후보로 "통상 변동 대역"(과거 월간 Δ의
median ± 3·MAD)을 도입했으나, 채점 실측에서 검정력이 없음이 드러났다
(적대 검증 CONFIRMED):

- 대역 폭의 사실상 전부가 계절 진폭이다 (이벤트 제거 base 이력의 MAD와
  계절 성분만의 MAD가 정확히 일치). rise +41.4억(+9.9%)도 '통상 범위 내'.
- fall의 '이탈' 검출조차 6월 이벤트가 이력 마지막 Δ를 왜곡해 MAD를 절반화한
  **이력 오염의 인공물**이었다 — 오염 없는 base 이력 대역으로는 fall -37.5억도
  '통상'.
- n=5 표본 위의 median±3·MAD는 통계적으로 무의미한 수준이다.

## 결정

1. 대역의 지위는 **ledger 진단 항목·설명 요구 트리거**로 한정한다 — 게이트도
   검정도 아니다. legacy-notes 함정 3(p<0.05 의례의 재림 금지)과 일관.
2. 채점(score.py E)은 데이터 대역과 반사실(base) 대역을 병기하고, 무검정력
   경고를 의무 출력한다 — 대역이 성공한 것처럼 보이는 케이스가 오염의
   산물일 수 있음을 숨기지 않는다.
3. 미끼 기각(D) 채점도 대역 폭/슬라이스 규모 비율을 병기해, "실패할 수 없는
   시험의 통과"를 성과로 오독하지 않게 한다.
4. δ_min·대역의 이중 기준 정식화(실무 임계 + 통상 변동)는 계절조정과 장기
   이력 확보 후로 미룬다 — 그 전에 대역을 판정 근거로 승격하지 않는다.

## 결과

- C3 게이트 재정의 논의("유의미한 변화인가")에 실측 근거가 생김: 원시 MoM Δ
  기반의 어떤 단순 대역도 계절이 지배하는 한 판정 근거가 될 수 없다.
- 개선 경로(우선순위 순): 계절조정 후 대역, 일 단위 잔차 기반 월 스케일 추정,
  이벤트 조정 이력(등록 이벤트 선언치 차감), 이력 연장.

## 재검토 조건

추세/변곡 연산자(registry §4.3) 구현 시 노이즈 모형과 함께 재설계.
