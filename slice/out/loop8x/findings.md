# ⑧작문 확장 측정 — rise/flat/fall_dirty × N=10 해석 (2026-08-12)

측정 설계: Track 2a 시뮬레이터 원장 3종을 시나리오 중립 러너(run_sim.py)로
번들화하고, 동일 계약(v0.1)·동일 장르(CFO 메모)·1회 작성으로 각 10회 독립 생성.
정답지(truth.json) 차단. 기준선은 fall 원 시나리오 N=20. 기계 측정치는
[measurement.md](measurement.md)·[metrics.json](metrics.json). 비용: 서브에이전트
토큰 약 144만, 벽시계 9.9분.

## 1. 계약 §12-1 "상승 관대화" — 이 표본에서 기각

상승(rise, +41.4억/+9.9%)에서 인과 단정이 관대해진다는 §12-1의 우려는 관측되지
않았다: 헤지 비율 0.10(fall 0.101과 동일), 무헤지 단정 어구("덕분/견인/이끌")
0건, R01~R03 발화 0건, 미특정 이벤트 3쌍 중첩의 기권 100%, 잔차 귀속 시도 0%,
조건부 헤드라인 100%. VRM 단가 효과(+10.5억)와 가격 개편(E6)의 정합은 전원이
인용하되 시사 어법에 묶었다. 계약·번들 구조는 방향 비대칭을 만들지 않는다 —
단, 이는 작문 에이전트에 대한 실증이고, §12-1이 원래 겨냥한 인간 표본의 상승
어법은 여전히 미검증이다.

## 2. flat — 무변화 보고는 형태 자체가 다르다

- 분량 2,735 ± 196자(fall 대비 -24%), 인용 수치 32.5개(-37%), 헤지 비율
  0.05(절반) — 헤지할 원인 서사 자체가 없으니 사실 진술 위주가 된다.
- 대역 인용 100%, 소폭·통상 명시 100%, 이벤트 부재 명시 실질 100%(정규식 80%
  + 수동 확인 2건 — "원인 후보가 현재 확인된 것이 없어" 류 변형).
- **원인 날조 0건.** 원인 어휘 토큰(행사·프로모션 등)은 전 메모에서 나타나지만
  전부 부재 진술("등록 이벤트 0건")과 패턴 정합 어법("가격이 아니라 수요 쪽
  요인과 정합")이다.
- δ_min(2.0억)과 대역의 상반된 판정을 다수 메모가 정확히 양립 처리: "무시
  기준(2.0억)은 넘어선 감소이므로 원인 확인은 필요하나, 통상 대역 내이므로
  이례적으로 단정하지 않는다"(memo_03). ADR-0004의 '트리거이지 검정 아님'
  지위가 지면에서 그대로 재현됐다.

## 3. fall_dirty — 정직한 축소, 그리고 커널의 빚

- 인용 수치 14.5 ± 1.3개 — fall의 28%. 분해가 거부되면 지면의 숫자도 준다.
  숫자 개수 자체가 정직성의 프록시가 된다.
- 분해 거부의 요약 전달 80%; 20%(memo_01·07)는 거부를 본문 섹션으로 미루고
  요약은 총 Δ와 이벤트로 채웠다 → **계약 v0.2 후보: 게이트 거부는 요약 의무**
  (v0.1-1 헤드라인 정합 규칙의 게이트 버전).
- 게이트 상세의 소비: "채널에 등록되지 않은 값('마켓플레이스') 유입", "NULL
  11행"이 본문 설명과 데이터 수리 요청(100%)으로 변환됐다.
- **오염 원장 위 이벤트 실측치에 품질 한정을 단 메모는 40%.** 번들 자체가 스캔
  결과를 오염 표시 없이 제공하므로(커널 공백: event_overlap_scan에 커버리지
  게이트가 없다 — 분해 3축이 거부된 원장에서 슬라이스 실측은 무사통과), 4/10은
  번들이 주지 않은 경고를 채널 오염에서 스스로 추론한 것이다. 이 추론은 작문의
  몫이 아니라 커널의 몫 → **백로그 승격: 스캔에도 커버리지 게이트 또는 오염
  플래그**.

## 4. 린트 3라운드 — 시나리오 모양이 바뀔 때마다 새 오탐 층

이번 라운드 명목 BLOCK 26건(rise 14·flat 3·dirty 9)도 전수 판정 결과 작문 결함
0건, 린트 오탐 4계층:

1. **반올림 인용** — 원시 건수 41.98만을 "약 42.0만 건"으로 (원 시나리오는
   건수가 정수라 잠복해 있었다) → 만 단위 표기에 소수 1자리 반올림 변형 허용.
2. **콤마 자릿수 표기** — "364,800"을 364와 800으로 토큰 분해 → R06 토크나이저
   콤마 그룹 인식.
3. **산술 대조 파생치** — 선언-실측 차(-3.9 vs -4.2의 0.3억), 공유 슬라이스
   기간 간 Δ(32.3→19.9의 -12.4억). '산술 대조 가능' 등급이 장려하는 계산이
   화이트리스트에 없었다 → 이벤트 행·중첩 플래그 파생치 등재.
4. **R01의 과정 설명 오폭** — "계획 기준선이 없기 때문"(인프라 부재 설명)을
   인과 단정으로 차단 → 인프라 명사 한정 제외.

수리 후 3 시나리오 전부 BLOCK 0%, fall N=20·report_agent.md 회귀 없음.
N=20의 교훈이 강화된다: **린트 화이트리스트의 완전성은 시나리오 다양성의
함수다 — 새 번들 모양 하나가 새 오탐 계층 하나를 드러낸다.** 작문 품질 신호는
3라운드 연속 0건.
